About ArghoSite

ArghoSite is an AI-powered job finder that reads your resume, extracts your skills, and searches LinkedIn and Naukri to surface the best-matching job openings — ranked by a skill-match score.

Tech Stack
  • Flask — Python web framework
  • pypdf / python-docx — Resume parsing
  • BeautifulSoup4 + requests — Job board scraping
  • Bootstrap 5 — Responsive UI
Part of the Automation Framework

This web app lives inside C:\Automation_Desktop_Mobile_Web\WebApp_ArghoSite\ and can be tested using the Selenium Page Objects in the parent framework.
